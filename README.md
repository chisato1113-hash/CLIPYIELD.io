# CLIPYIELD — 動くフロントエンド版

公式ライセンスのモーションコミックを切り抜いて、再生報酬（TIER1）とグッズ成果報酬（TIER2）の
二階建てで稼ぐクリッパー向けプラットフォームのランディングページ＋アプリ画面です。

元は「社内デザイン確認用プロトタイプ」の静的LPでした。そこにログイン・登録・ダッシュボードを追加し、
**バックエンドなし（ブラウザ内 localStorage 保存）で実際に触って動く**状態にしたものです。
GitHub Pages などの静的ホスティングにそのまま公開できます。

## 使える機能（動くフロント）

- **登録 / ログイン / ログアウト** … メール＋パスワードでアカウント作成・認証。セッションを保持。
- **認証ガード** … 未ログインで `dashboard.html` を開くと `login.html` へ自動リダイレクト。
- **SNS連携（審査制）** … TikTok / Reels / Shorts / X を申請すると「審査中 → 承認済み」に（デモは数秒で自動承認。本番は運営審査を想定）。
- **本人確認（KYC・専用ページ）** … `kyc.html` に遷移し、書類種別（パスポート/運転免許証/マイナンバーカード）→ 本人確認書類 → セルフィーをアップロードして申請。「審査中 → 承認済み」に（デモは数秒で自動承認）。**アップロード画像は保存しません**（書類種別と状態のみ記録。本番はKYC事業者へ安全送信する前提）。
- **案件の制限** … 「本人確認必須」の成果報酬案件は個人ID登録後に参加可能。再生報酬のみの案件は本人確認なしで参加可能。
- **案件ボード** … 映画・ドラマ・アニメ・音楽・漫画・YouTubeの**カテゴリー別フィルター**（件数付き）で絞り込み可能。各案件に**募集国**（🇺🇸🇯🇵🇰🇷…）を表示。グッズ成果報酬あり（二階建て）／再生報酬のみ（TIER1のみ）の両方に対応。案件に「参加する」と専用の紹介リンクを発行。デスクトップ3列／タブレット2列／モバイル1列のレスポンシブ。
- **投稿登録** … 投稿URL・再生数・売上を登録すると、案件ごとの料率で
  TIER1（再生 × 単価）＋ TIER2（売上 × 30〜60%）を自動計算。
- **ダッシュボード** … 確定報酬・総再生数・購入件数・参加案件数などのKPI、報酬内訳、
  ランキング（自分の順位を反映）、支払い方法の選択を表示。
- **LPナビの状態切替** … ログイン中は「ログイン/無料ではじめる」が「ダッシュボード」に変わる。

> データはすべて閲覧しているブラウザ内（localStorage）にのみ保存されます。
> 本物のサーバー認証・決済ではありません。実運用には別途バックエンドが必要です（下記参照）。

## 法務ページ（4種）

`01〜04_◯◯_叩き台.md.docx` の草案内容を反映した各ページです。フッターの **LEGAL** 列と
登録画面の同意リンクから遷移でき、各ページ末尾から相互に行き来できます。

- `terms.html` … **利用規約**（全13条）
- `clipper-terms.html` … **クリッパー規約**（全15条・報酬/支払/成果計測）
- `privacy.html` … **プライバシーポリシー**（GDPR/PIPA/PIPL等の国際移転を含む）
- `tokushoho.html` … **特定商取引法に基づく表記**（Z-IPが販売主体となる場合のひな形）

> いずれも冒頭に「叩き台・法務レビュー前」の注記があり、未決定箇所は
> <mark>【要確定】</mark> ハイライトで明示しています。**施行前に弁護士のレビューが必要です。**

## クライアント入稿ポータル（ID/PASS）

権利者・広告主が案件を入稿する画面です。`client-login.html` でログイン後、`client.html` の
フォームで以下を設定できます（未ログインでは自動的にログイン画面へリダイレクト）。

1. **素材格納** … 動画/静止画/音声のアップロード（デモはファイル名のみ記録）＋許諾範囲
2. **支払い再生単価設定** … TIER1 再生単価（¥/再生）＋ TIER2 料率（30〜60%）
3. **グッズアフィリエイトリンク（自動生成）** … 商品／ストアURLを入力すると
   `https://go.clipyield.io/a/<コード>?to=<商品URL>` を自動生成。
4. **期限** … 募集締切日
5. **NG事項** … ブランド毀損を避けるための禁止表現（チップ選択＋自由記入）
6. **対象SNS** … TikTok / Instagram Reels / YouTube Shorts / X
7. **対象国** … 日本 / アメリカ / インドネシア / タイ / 韓国 / 台湾 / 全世界
8. **上限予算** … TIER1 の予算上限（再生換算の目安を自動表示）

入稿すると受付番号を発行し、内容を localStorage に保存します（デモ）。

```
デモ用ログイン →  ID: clip-demo  /  PASS: clip1234
```

### アフィリエイトリンクとクリッパー報酬の連動

入稿した案件は **クリッパーのダッシュボード（案件ボード）に自動で流れ込みます**（`cy.js` の
`clientCampaigns()` / `allCampaigns()` で橋渡し）。クリッパーが参加すると、クライアントの
グッズアフィリエイトリンクを起点に各クリッパー固有の識別子（`&clip=<handle>`）を付与した
**専用アフィリエイトリンク**が発行され、そのリンク経由の購入がクリッパーの報酬画面で
**TIER2 グッズ成果報酬／「リンク経由購入」KPI** として紐づきます。

### 案件進捗ダッシュボード（`client-dashboard.html`）

META の広告管理画面を参考にした、案件別の進捗ビューです。案件セレクタと
**日次／週次／月次**トグルで以下を確認できます。

- **参加クリッパー数**、総再生数、エンゲージメント、リンククリック、CV、CVR のKPI
- **クリッパー別 再生数ランキング**（CV付き）
- **媒体別パフォーマンス表**：再生数／ENG／リンククリック／CTR／CV／CVR（合計行つき）
- 再生数／クリック／CV を切り替えられる**時系列バーチャート**

> 指標は実APIがないため、案件IDから**決定論的に生成した擬似データ**です
> （同じ案件は毎回同じ数値）。本番は各SNS/広告APIと購入トラッキングに接続する前提です。

### 支払い方法の登録（`client-billing.html`）

クライアント（入稿主）が案件予算を支払うための支払い方法を登録します。2方式に対応：

1. **クレジットカード** … Visa / Mastercard / Amex / JCB / Diners / Discover。
   カード番号は Luhn チェックのみ行い、**保存するのはブランドと下4桁だけ**（番号・CVCは保存しません）。
2. **銀行振込（請求書払い）** … 請求先会社名・担当者・請求書送付先メール・適格請求書登録番号
   （インボイスT番号）・支払いサイト・請求先住所。

登録済みカードはブランド／下4桁／名義／有効期限をカード風UIで表示。入稿フォームには
「支払い方法が未登録です」のバナーを表示します（`CYClient.getBilling()` で判定）。

> ⚠️ **これはプロトタイプです。実在するカード番号・口座番号は入力しないでください。**
> 番号は保持せず（`client.js` は brand + last4 のみ保存）、本番では PCI DSS 準拠の決済代行
> （Stripe / GMO 等）でトークン化して扱う前提です。デモ用テスト番号 `4242 4242 4242 4242`
> で動作確認できます。

## SEOコラム（クリッパー募集）と運営管理画面

クリッパー募集用のSEOコラムと、その運営管理画面（記事CRUD）です。データ層は `column.js`。

### 公開側（SEO対策）

- `column.html` … 記事一覧。カテゴリー絞り込み、カードグリッド、`Blog` の JSON-LD。
- `article.html?slug=<slug>` … 記事詳細。読み込み時に **title / meta description / OGP /
  Twitter Card / canonical / JSON-LD（`BlogPosting` ＋ `BreadcrumbList`）** を動的注入。
  本文は軽量Markdown（見出し・リスト・引用・リンク・画像・強調）を安全にHTML化（XSS対策済み）。
  末尾にクリッパー登録CTAと関連記事。

> ⚠️ SEOの本番運用では、クライアント側レンダリングよりも **静的生成（SSG）/ SSR** で
> 記事HTMLを事前生成する方が確実です。本デモは localStorage ＋ JS描画のため、将来は
> ヘッドレスCMS / SSG（記事データは同じスキーマ）へ移行する前提です。

### 運営管理画面（`admin-login.html` → `admin.html`）

- 記事の **作成・編集・削除**、**下書き／公開** の切り替え、公開前プレビュー（`?preview=1`）。
- 設定項目：タイトル・スラッグ（自動）・カテゴリー・タグ・**カバー画像（URL または
  アップロード＝base64、1.5MBまで）**・抜粋・本文（Markdown＋ライブプレビュー）・
  **SEOメタ（SEOタイトル／メタディスクリプション／キーワード）**。

```
運営デモログイン →  ID: admin  /  PASS: clipyield-admin
```

### SEO記事作成AIとの連携（将来）

管理画面の「🤖 SEO記事作成AI（下書き生成）」は、トピック／キーワードから下書きを生成します。
現状は `column.js` の `CYColumn.ai.generate()` によるローカルのテンプレ生成（デモ）ですが、
**手動フローとAIフローが同じコードパスを通る**よう設計しています：

```
AIが下書き生成  → CYColumn.createDraft({source:"ai", ...})
（任意で人がレビュー/編集）→ CYColumn.save(article)
公開（手動 or 自動）→ CYColumn.publish(id)
```

本番連携は `AI_CONFIG.endpoint` を設定し、`aiGenerate()` 内の `fetch()`（コメントで明示した
INTEGRATION POINT）を実APIやMCPツールに差し替えるだけで、生成→レビュー→公開の自動フローが回ります。
`AI_CONFIG.autoPublish` を `true` にすればレビューなしの自動公開も可能です。

```bash
cd clipyield-site
python3 -m http.server 8891
```

## GitHub Pages に公開する

1. リポジトリ（例: `CLIPYIELD.io`）のルートに、この `clipyield-site` の中身
   （`index.html` などを直下に）配置します。
2. GitHub の **Settings → Pages** で、公開ブランチ（例: `main` / `root`）を選択して保存。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

既存の https://chisato1113-hash.github.io/CLIPYIELD.io/ を更新する場合は、
そのリポジトリの `index.html` を本 `index.html` に差し替え、`signup.html` `login.html`
`dashboard.html` `assets/` を同じ階層に追加してください。

## 「本物」にするには（次のステップ）

現状はフロントのみのデモです。実サービス化する場合は以下が必要です。

- サーバー認証（例: Supabase Auth / Firebase Auth）— パスワードを安全に扱う
- データベース（案件・投稿・報酬・支払い）
- SNS連携と再生数の自動集計、購入トラッキング（TIER2）
- 支払い処理（銀行振込 / PayPal / USDC など）

必要になったら、この画面設計をそのまま土台にしてバックエンドを接続できます。

## 運用ルール v3 改修（2026-09）＋ デザイン刷新

### ポジショニングの反転：「審査なし」→「審査制（公式切り抜き師）」
案件を受けられるのは**審査を通過した Clipyield 公式切り抜き師のみ**。LP・signup・article・column・法務・DICT(en/zh) から「審査なし／参加条件なし／no approval／无需审核」系の表現を全撤去し、審査制を強みとして再構成（比較表・FAQ・案件カード＝ティア表示・BAN断定の緩和）。

### 主な機能（`assets/cy.js`）
- **審査制（applicationStatus: unsubmitted→pending→approved/rejected）**：本人確認(KYC・全員必須)＋活動用アカウント登録 → 審査申請 → **手動承認（デモは運営承認ボタン。自動承認しない。本番は運営審査2〜3営業日）**。承認者のみ `joinCampaign` 可。
- **ティア制（TIERS: bronze/silver/gold）**：`minTier`で案件アクセス制御。単価0.03〜0.5円に分散。累計再生で自動昇格（silver=100万／gold=1,000万・違反ゼロ）、違反で降格。`syncProgress()` が投稿登録時に集計・昇格判定。
- **最低保証（guarantee）**：新規アカウント審査通過者に月3万円・最長3ヶ月・差額補填。条件＝月20本以上・審査却下率が規定以下・違反ゼロ。認定アカウント利用者は対象外。`earnings()` が差額を算出。
- **早期出金（payoutSpeed: standard/early）**：早期は手数料4%（`EARLY_PAYOUT_FEE_RATE`）。標準は月末締め→翌月10日頃確定→翌月末以降無料。
- **アカウント種別（accountType: new/certified）**：原則は新規（最低保証対象）、既存は認定アカウント（基準同意・上位ティア開始・保証対象外）。複数アカウント可。
- **重複投稿検知・1日上限・PR表記（addPost）**：`clipId`重複は2件目以降 `rewardEligible:false`（TIER1/2集計外）。1アカウント1日5本上限（`DAILY_POST_LIMIT`）。PR表記チェック未確認は登録不可（景表法・ステマ規制）。案件ごとに `disclosureText` を保持しコピー可能表示。
  - **NOTE:** フロントのみでは真の重複判定は不可能。**本番は動画の知覚ハッシュ（perceptual hash）照合が必要**。
- クライアント入稿（`client.html`/`assets/client.js`→`cy.js clientCampaigns`）：`minTier`・`disclosureText`・単価レンジ(¥0.03〜0.50) に対応。

### 権利者向けページ（新規）
- **`for-clients.html`**：IP専業・成果報酬・審査済み切り抜き師・レビュー工数ゼロ・国別可視化・品質担保／責任分界（協議条項）・FAQ・CTA。日英中対応（ページ内DICT）。料率は未確定のため「お問い合わせ」。
- 導線：LPの PCヘッダー／モバイルヘッダー／フッターPLATFORM列／本文末に「権利者の方へ」を追加。フッター「クライアント入稿」は `client.html` へ。

### デザイン刷新（clipping.net 参考・差し色オレンジ）
- モノクロ基調＋**Interフォントの極太タイポ**、主ボタン＝黒（`.btn-primary`）、オレンジは差し色（見出しアクセント・`.btn-accent`・ドット・ティア/バッジ）。`index.html` インライン `<style>` と `assets/cy.css`（`@import` で Inter）を統一。
- ヒーローに**スマートフォンのモックアップ**（縦型クリップ再生UI）＋浮遊スタットカード。
- **クライアントロゴのループ表示**（左流れ）：世界的著名企業のワードマーク。※誤認防止のため実ロゴ画像は複製せず、モノクロ社名＋「イメージ・サンプル／実在の取引を示すものではない」明記。
- **案件例クリップのショーケース**（9:16縦型カード）。
