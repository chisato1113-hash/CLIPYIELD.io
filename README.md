# CLIPYIELD — 動くフロントエンド版

公式ライセンスのモーションコミックを切り抜いて、再生報酬（TIER1）とグッズ成果報酬（TIER2）の
二階建てで稼ぐクリッパー向けプラットフォームのランディングページ＋アプリ画面です。

元は「社内デザイン確認用プロトタイプ」の静的LPでした。そこにログイン・登録・ダッシュボードを追加し、
**バックエンドなし（ブラウザ内 localStorage 保存）で実際に触って動く**状態にしたものです。
GitHub Pages などの静的ホスティングにそのまま公開できます。

## ファイル構成

```
clipyield-site/
├── index.html          # ランディングページ（日英中3言語・収益シミュレーター付き）
├── signup.html         # クリッパー登録
├── login.html          # クリッパーログイン
├── dashboard.html      # クリッパー用ダッシュボード
├── kyc.html            # 本人確認（KYC）専用ページ
├── terms.html          # 利用規約
├── clipper-terms.html  # クリッパー規約
├── privacy.html        # プライバシーポリシー
├── tokushoho.html      # 特定商取引法に基づく表記
├── client-login.html   # クライアント（権利者/広告主）ログイン
├── client.html         # クライアント案件入稿フォーム
├── assets/
│   ├── cy.css          # 共有デザインシステム（全ページ・法務・入稿UIを含む）
│   ├── cy.js           # クリッパー側の認証・データ層（localStorage）
│   └── client.js       # クライアント側の認証・入稿データ層（localStorage）
└── README.md
```

## 使える機能（動くフロント）

- **登録 / ログイン / ログアウト** … メール＋パスワードでアカウント作成・認証。セッションを保持。
- **認証ガード** … 未ログインで `dashboard.html` を開くと `login.html` へ自動リダイレクト。
- **SNS連携（審査制）** … TikTok / Reels / Shorts / X を申請すると「審査中 → 承認済み」に（デモは数秒で自動承認。本番は運営審査を想定）。
- **本人確認（KYC・専用ページ）** … `kyc.html` に遷移し、書類種別（パスポート/運転免許証/マイナンバーカード）→ 本人確認書類 → セルフィーをアップロードして申請。「審査中 → 承認済み」に（デモは数秒で自動承認）。**アップロード画像は保存しません**（書類種別と状態のみ記録。本番はKYC事業者へ安全送信する前提）。
- **案件の制限** … 「本人確認必須」の成果報酬案件は個人ID登録後に参加可能。再生報酬のみの案件は本人確認なしで参加可能。
- **案件ボード** … 映画・ドラマ・アニメ・音楽・漫画・YouTubeの**カテゴリー別フィルター**（件数付き）で絞り込み可能。各案件に**募集国**（🇺🇸🇯🇵🇰🇷…）を表示。グッズ成果報酬あり（二階建て）／再生報酬のみ（TIER1のみ）の両方に対応。案件に「参加する」と専用の紹介リンクを発行。デスクトップ3列／タブレット2列／モバイル1列のレスポンシブ。
- **投稿登録** … 投稿URL・再生数・売上を登録すると、案件ごとの料率で
  TIER1（再生 × 単価）＋ TIER2（売上 × 30〜60%）を自動計算。
- **ダッシュボード** … 確定報酬・総再生数・購入件数・参加案件数などのKPI、報酬内訳、
  ランキング（自分の順位を反映）、支払い方法の選択を表示。
- **LPナビの状態切替** … ログイン中は「ログイン/無料ではじめる」が「ダッシュボード」に変わる。

> データはすべて閲覧しているブラウザ内（localStorage）にのみ保存されます。
> 本物のサーバー認証・決済ではありません。実運用には別途バックエンドが必要です（下記参照）。

## 法務ページ（4種）

`01〜04_◯◯_叩き台.md.docx` の草案内容を反映した各ページです。フッターの **LEGAL** 列と
登録画面の同意リンクから遷移でき、各ページ末尾から相互に行き来できます。

- `terms.html` … **利用規約**（全13条）
- `clipper-terms.html` … **クリッパー規約**（全15条・報酬/支払/成果計測）
- `privacy.html` … **プライバシーポリシー**（GDPR/PIPA/PIPL等の国際移転を含む）
- `tokushoho.html` … **特定商取引法に基づく表記**（Z-IPが販売主体となる場合のひな形）

> いずれも冒頭に「叩き台・法務レビュー前」の注記があり、未決定箇所は
> <mark>【要確定】</mark> ハイライトで明示しています。**施行前に弁護士のレビューが必要です。**

## クライアント入稿ポータル（ID/PASS）

権利者・広告主が案件を入稿する画面です。`client-login.html` でログイン後、`client.html` の
フォームで以下を設定できます（未ログインでは自動的にログイン画面へリダイレクト）。

1. **素材格納** … 動画/静止画/音声のアップロード（デモはファイル名のみ記録）＋許諾範囲
2. **支払い再生単価設定** … TIER1 再生単価（¥/再生）＋ TIER2 料率（30〜60%）
3. **期限** … 募集締切日
4. **NG事項** … ブランド毀損を避けるための禁止表現（チップ選択＋自由記入）
5. **対象SNS** … TikTok / Instagram Reels / YouTube Shorts / X
6. **対象国** … 日本 / アメリカ / インドネシア / タイ / 韓国 / 台湾 / 全世界
7. **上限予算** … TIER1 の予算上限（再生換算の目安を自動表示）

入稿すると受付番号を発行し、内容を localStorage に保存します（デモ）。

```
デモ用ログイン →  ID: clip-demo  /  PASS: clip1234
```

## ローカルで確認する

`file://` だとブラウザによっては動作が制限されるため、簡易サーバー経由での確認を推奨します。

```bash
cd clipyield-site
python3 -m http.server 8891
```

ブラウザで http://localhost:8891/ を開きます。

## GitHub Pages に公開する

1. リポジトリ（例: `CLIPYIELD.io`）のルートに、この `clipyield-site` の中身
   （`index.html` などを直下に）配置します。
2. GitHub の **Settings → Pages** で、公開ブランチ（例: `main` / `root`）を選択して保存。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

既存の https://chisato1113-hash.github.io/CLIPYIELD.io/ を更新する場合は、
そのリポジトリの `index.html` を本 `index.html` に差し替え、`signup.html` `login.html`
`dashboard.html` `assets/` を同じ階層に追加してください。

## 「本物」にするには（次のステップ）

現状はフロントのみのデモです。実サービス化する場合は以下が必要です。

- サーバー認証（例: Supabase Auth / Firebase Auth）— パスワードを安全に扱う
- データベース（案件・投稿・報酬・支払い）
- SNS連携と再生数の自動集計、購入トラッキング（TIER2）
- 支払い処理（銀行振込 / PayPal / USDC など）

必要になったら、この画面設計をそのまま土台にしてバックエンドを接続できます。
